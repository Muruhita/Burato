## Информация
Бот для простого сайта зявок фибов,
используемы для повышения и всяких простых задач, написанный через ИИ

## Функцилонал:
* Антиспам(6 заявок с кд в 20 сек, в час, более = бан на 4 дн)
* Автобан(За Банворд, спам)
* Логи(Действий, Заявок, Банвордов, Автобанов, Ошибок)
* Админка(Разбан/Бан и управление)
* Загрузка фото через API https://i.ibb.co/
* Заход через авторизацию в боте
* Сбор ID,Username,Avatar
* Сохранение данных в профиле и их автозаполнение
* Список Юзеров
* Справка с помощью которую можно дополнять
* ToS и Privacy как подтверждение честности
* Страница с доступными для загрузки хостингами
* Решение проблемы дискорд
* Страница с Полезными ссылками для Majestic

## Планируется добавить:
* Добавление фото во всех формах где это нужно
* Улучшение внешнего вида сайта
* Повысить фукнционал
* Увеличить кол-во доступных Форм

## Хотелось, но не возможно(Причина):
* Определение роли участника например: наличие роли @FIB у типа, чтобы он мог кидать заявки(Невозможно без бота на сервере)
* Чтение заявок и показ их на сайте(Невозможно без бота на серваке)
* Сделать заявку функциональными, типа их можно отклонять кнопкой или принимать и это приходило в ЛС участнику как уведомление(Невозможно без бота на серваке, может не хватить бесплатного тарифа)
